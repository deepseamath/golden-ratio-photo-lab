# 황금비 포토 연구소

React + Vite 기반의 모바일 우선 웹앱입니다. 학생이 QR로 접속해 사진을 업로드하거나 촬영하면, 사진 중앙의 얼굴 영역 기준으로 황금직사각형과 황금나선을 표시하고 포토카드를 PNG로 저장할 수 있습니다.

## 주요 기능

- 사진 업로드 및 모바일 촬영 입력
- 업로드한 사진 카드 표시
- 사진 중앙 얼굴 영역에만 황금비 오버레이 표시
- 황금비 지수, 점수, 16개 유형 중 하나 표시
- 아이돌 포토카드 느낌의 결과 카드
- `html2canvas`를 이용한 PNG 저장

## 실행 방법

1. Node.js를 설치합니다.
   - 처음이라면 [Node.js 공식 사이트](https://nodejs.org/)에서 LTS 버전을 설치하면 됩니다.

2. 이 폴더로 이동합니다.

```bash
cd golden-ratio-photo-lab
```

3. 필요한 패키지를 설치합니다.

```bash
npm install
```

4. 개발 서버를 실행합니다.

```bash
npm run dev
```

5. 터미널에 표시되는 주소를 브라우저에서 엽니다.
   - 보통 `http://localhost:5173` 입니다.

## 휴대폰 또는 태블릿에서 테스트하기

같은 Wi-Fi에 연결된 기기에서 접속하려면 `npm run dev`를 실행한 뒤 터미널에 표시되는 Network 주소를 사용합니다.

예시:

```text
http://192.168.0.10:5173
```

이 주소를 QR 코드로 만들면 학생들이 QR로 접속할 수 있습니다.

## 현재 구현 기준

1차 버전은 실제 얼굴 인식을 사용하지 않습니다. 대신 사진 중앙의 얼굴 영역을 기준으로 황금직사각형과 황금나선을 배치합니다. 그래서 얼굴이 사진 중앙에 오도록 촬영하면 가장 자연스럽게 보입니다.

## 빌드

배포용 파일을 만들려면 아래 명령어를 실행합니다.

```bash
npm run build
```

빌드 결과는 `dist` 폴더에 생성됩니다.
